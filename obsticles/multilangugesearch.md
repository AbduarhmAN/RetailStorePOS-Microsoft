# Multi-Language Global Research Prompt

Use the following prompt to trigger an exhaustive, cross-regional technical audit for complex bugs or documentation gaps:

---

## The Command
"Perform an exhaustive technical research audit in 5 separate rounds. For each round, you must conduct searches in these 5 specific languages: Hebrew, Russian, Chinese, German, and English. CRITICAL RULE: You must NEVER use the same keywords across the different languages; you must use unique, localized technical terms for each language to ensure we find diverse solutions from different global developer communities. Summarize the findings from all 5 perspectives."

---

## Expected Methodology
1. **Language Scope**: Hebrew (UnderGround/Forums), Russian (Habr/StackOverflow), Chinese (CSDN/Zhihu), German (Community/MS Docs), English (Mainstream).
2. **Round Structure**: 5 distinct investigation phases to drill deeper into the problem.
3. **Keyword Diversity**: No direct translations. Each language must search for its own specific "dialect" of the technical problem.
4. **Synthesis**: A unified report that combines insights from all linguistic regions.
